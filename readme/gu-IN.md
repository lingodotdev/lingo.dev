## ટીમો Lingo.dev પર લોકલાઇઝેશન એન્જિન બનાવે છે

[લોકલાઇઝેશન એન્જિન](https://lingo.dev/en/docs/platform/engines) એ સ્ટેટફુલ અનુવાદ API છે, જેને તમારી ટીમ ગોઠવે છે અને Lingo.dev ચલાવે છે. દરેક પ્રોડક્ટ માટે, દરેક સામગ્રી પ્રકાર માટે અથવા દરેક બ્રાન્ડ માટે એક એન્જિન બનાવો. એન્જિન મારફતે જતી દરેક વિનંતી તેમાં તમે ગોઠવેલી દરેક વસ્તુને પ્રાથમિકતાના નક્કી કરેલા ક્રમમાં લાગુ કરે છે:

| સ્તર | તમે શું ગોઠવો છો | દસ્તાવેજીકરણમાંથી |
| --- | --- | --- |
| [LLM મોડલ્સ](https://lingo.dev/en/docs/platform/llm-models) | ક્રમબદ્ધ વિકલ્પો સાથે, દરેક ભાષા-જોડી માટે કયું મોડલ કામ કરે છે | 400+ મોડલ્સ; પ્રતિભાવમાં કયું મોડલ ચલાવાયું તે નામ સાથે બતાવે છે |
| [બ્રાન્ડ અવાજ](https://lingo.dev/en/docs/platform/brand-voices) | દરેક ભાષામાં તમારું પ્રોડક્ટ કેવી રીતે બોલે છે, દરેક લોકેલ માટે એક લખાણ | દરેક બજાર માટે ટોન અને ઔપચારિકતા |
| [નિયમો](https://lingo.dev/en/docs/platform/rules) | સામાન્ય મોડલથી ચૂકી જતી ભાષાકીય પરંપરાઓ | સ્પેનિશમાં વિશેષણનું સ્થાન, ટકાવારી ચિહ્ન પહેલાં ખાલી જગ્યા |
| [શબ્દકોશ](https://lingo.dev/en/docs/platform/glossaries) | અર્થના આધારે મેળ ખાતા, દરેક લોકેલ માટે ચોક્કસ શબ્દ-મેળાપ | "911" યુરોપિયન બજારો માટે "112" બને છે; પ્રોડક્ટનાં નામ જેમનાં તેમ જ રહે છે |
| [AI સમીક્ષકો](https://lingo.dev/en/docs/platform/ai-reviewers) | દરેક અનુવાદ પછી ચાલતું સ્કોરિંગ | GEMBA સ્કોર્સ, BERTScore, શબ્દકોશ અનુરૂપતા |

શબ્દકોશો, નિયમસંગ્રહો અને બ્રાન્ડ અવાજો તમારી સંસ્થાના હોય છે, અને એન્જિન તેમને જોડાણ દ્વારા લાગુ કરે છે. એક શબ્દકોશ પાંચ એન્જિનને સંભાળી શકે છે, અને એક ફેરફાર પાંચેય સુધી પહોંચે છે. ફેરફાર લાઇવ થાય તે પહેલાં [Playground](https://lingo.dev/en/docs/platform/playground) માં તેને ચકાસો: એક એન્જિનની સરખામણી મૂળ મોડલ સામે કરો, અથવા બે એન્જિનને બાજુબાજુ સરખાવો. એન્જિનો પ્લેટફોર્મ પર ગોઠવાય છે, જ્યાં લોકલાઇઝેશન ટીમ લોકલાઇઝેશન માળખું સંચાલિત કરે છે.

## કોડમાંથી તમારા એન્જિન સુધી પહોંચો

રિપોઝિટરીમાં રહેલી સામગ્રીનો અનુવાદ કરો. `lingo push` ફાઇલોને `.lingo/config.json` માં નામ આપેલા એન્જિન સુધી મોકલે છે, અને `lingo pull` કોઈપણ મશીન પરથી અનુવાદો પાછા લખે છે:

```bash
npm install -g @lingo.dev/cli
lingo init && lingo link
lingo push
```

અથવા, ID દ્વારા નામ આપી સીધું એન્જિન કૉલ કરો:

```javascript
const res = await fetch("https://api.lingo.dev/process/localize", {
  method: "POST",
  headers: { "X-API-Key": process.env.LINGO_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({
    engineId: "eng_abc123",
    sourceLocale: "en",
    targetLocale: "de",
    data: { greeting: "Hello, world!", cta: "Get started" },
  }),
});

const { data, model, usage } = await res.json();
// data:  { greeting: "Hallo, Welt!", cta: "Jetzt starten" }
// model: "anthropic/claude-sonnet-4.5"
// usage: { inputTokens: 2789, outputTokens: 861, cost: 0.023012 }
```
