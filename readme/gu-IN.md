## ટીમો Lingo.dev પર સ્થાનિકીકરણ એન્જિન બનાવે છે

[સ્થાનિકીકરણ એન્જિન](https://lingo.dev/en/docs/platform/engines) એ સ્ટેટફુલ અનુવાદ API છે જેને તમારી ટીમ ગોઠવે છે અને Lingo.dev ચલાવે છે. દરેક ઉત્પાદન, દરેક સામગ્રી પ્રકાર અથવા દરેક બ્રાન્ડ માટે એક બનાવો. એન્જિન દ્વારા કરાતી દરેક વિનંતી તમે ગોઠવેલી દરેક વસ્તુને નિશ્ચિત પ્રાથમિકતાના ક્રમમાં લાગુ કરે છે:

| સ્તર                                                            | તમે શું ગોઠવો છો                                                    | દસ્તાવેજોમાંથી                                                   |
| --------------------------------------------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| [LLM મોડલ્સ](https://lingo.dev/en/docs/platform/llm-models)     | દરેક ભાષા જોડી માટે કયું મોડલ સંભાળે છે, રેન્ક કરેલા ફોલબેક્સ સાથે  | 400+ મોડલ્સ; પ્રતિસાદ જે મોડલ ચાલ્યું તેનું નામ આપે છે           |
| [બ્રાન્ડ વૉઇસ](https://lingo.dev/en/docs/platform/brand-voices) | તમારું ઉત્પાદન દરેક ભાષામાં કેવી રીતે બોલે છે, લોકેલ દીઠ એક ટેક્સ્ટ | બજાર દીઠ સ્વર અને ઔપચારિકતા                                      |
| [નિયમો](https://lingo.dev/en/docs/platform/rules)               | સામાન્ય મોડલ ચૂકી જાય તેવા ભાષાકીય સંમેલનો                          | સ્પેનિશમાં વિશેષણની સ્થિતિ, ટકાવારી ચિહ્નો પહેલાં સ્પેસ          |
| [શબ્દકોશ](https://lingo.dev/en/docs/platform/glossaries)        | લોકેલ દીઠ ચોક્કસ શબ્દ મેપિંગ્સ, અર્થ દ્વારા મેળ ખાતા                | યુરોપીયન બજારો માટે "911" "112" બને છે; ઉત્પાદન નામો પસાર થાય છે |
| [AI સમીક્ષકો](https://lingo.dev/en/docs/platform/ai-reviewers)  | દરેક અનુવાદ પછી ચાલતું સ્કોરિંગ                                     | GEMBA સ્કોર્સ, BERTScore, શબ્દકોશ પાલન                           |

શબ્દકોશ, નિયમસંગ્રહો અને બ્રાન્ડ વૉઇસ તમારી સંસ્થાની છે, અને એન્જિન તેને જોડાણ દ્વારા લાગુ કરે છે. એક શબ્દકોશ પાંચ એન્જિનને સંચાલિત કરે છે, અને એક સંપાદન પાંચેય સુધી પહોંચે છે. તે લાઇવ થાય તે પહેલાં [પ્લેગ્રાઉન્ડ](https://lingo.dev/en/docs/platform/playground)માં ફેરફારનું પરીક્ષણ કરો: એન્જિનને રૉ મોડલ સામે અથવા બે એન્જિનને સાથે સાથે સરખાવો. એન્જિન પ્લેટફોર્મ પર ગોઠવવામાં આવે છે, જ્યાં સ્થાનિકીકરણ ટીમ સ્થાનિકીકરણ ઈન્ફ્રાસ્ટ્રક્ચર ચલાવે છે.

## કોડમાંથી તમારા એન્જિનો સુધી પહોંચો

રિપોઝિટરીમાં સામગ્રીનું ભાષાંતર કરો. `lingo push` ફાઇલોને `.lingo/config.json` માં નામવાળા એન્જિનને મોકલે છે, અને `lingo pull` કોઈપણ મશીનથી ભાષાંતર પાછા લખે છે:

```bash
npm install -g @lingo.dev/cli
lingo init && lingo link
lingo push
```

અથવા એન્જિનને સીધા જ તેની ID દ્વારા કૉલ કરો:

```javascript
const res = await fetch("https://api.lingo.dev/process/localize", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.LINGO_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    engineId: "eng_abc123",
    sourceLocale: "en",
    targetLocale: "de",
    data: { greeting: "Hello, world!", cta: "Get started" },
  }),
});

const { data, model, usage } = await res.json();
// data:  { greeting: "Hallo, Welt!", cta: "Jetzt starten" }
// model: "anthropic/claude-sonnet-4.5"
// usage: { inputTokens: 2789, outputTokens: 861, cost: 0.023012 }
```
