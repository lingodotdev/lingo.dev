## ਟੀਮਾਂ Lingo.dev 'ਤੇ ਸਥਾਨਕੀਕਰਨ ਇੰਜਨ ਬਣਾਉਂਦੀਆਂ ਹਨ

ਇੱਕ [ਸਥਾਨਕੀਕਰਨ ਇੰਜਨ](https://lingo.dev/en/docs/platform/engines) ਇੱਕ ਸਟੇਟਫੁਲ ਅਨੁਵਾਦ API ਹੈ, ਜਿਸਨੂੰ ਤੁਹਾਡੀ ਟੀਮ ਸੰਰਚਿਤ ਕਰਦੀ ਹੈ ਅਤੇ Lingo.dev ਚਲਾਉਂਦਾ ਹੈ। ਹਰ ਉਤਪਾਦ, ਹਰ ਸਮੱਗਰੀ ਕਿਸਮ ਜਾਂ ਹਰ ਬ੍ਰਾਂਡ ਲਈ ਵੱਖਰਾ ਇੰਜਨ ਬਣਾਓ। ਇੰਜਨ ਰਾਹੀਂ ਜਾਣ ਵਾਲੀ ਹਰ ਬੇਨਤੀ ਉਸ ਵਿੱਚ ਕੀਤੀ ਤੁਹਾਡੀ ਹਰ ਸੰਰਚਨਾ ਨੂੰ ਤਰਜੀਹ ਦੇ ਇੱਕ ਨਿਰਧਾਰਿਤ ਕ੍ਰਮ ਵਿੱਚ ਲਾਗੂ ਕਰਦੀ ਹੈ:

| ਪਰਤ | ਤੁਸੀਂ ਕੀ ਸੰਰਚਿਤ ਕਰਦੇ ਹੋ | ਦਸਤਾਵੇਜ਼ਾਂ ਵਿੱਚੋਂ |
| --- | --- | --- |
| [LLM ਮਾਡਲ](https://lingo.dev/en/docs/platform/llm-models) | ਹਰ ਭਾਸ਼ਾ ਜੋੜੇ ਨੂੰ ਕਿਹੜਾ ਮਾਡਲ ਸੰਭਾਲੇਗਾ, ਰੈਂਕ ਕੀਤੇ fallback ਸਮੇਤ | 400+ ਮਾਡਲ; ਜਵਾਬ ਵਿੱਚ ਚੱਲੇ ਮਾਡਲ ਦਾ ਨਾਮ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ |

ਸ਼ਬਦਾਵਲੀਆਂ, ਨਿਯਮ-ਸੈੱਟ ਅਤੇ ਬ੍ਰਾਂਡ ਦੀਆਂ ਆਵਾਜ਼ਾਂ ਤੁਹਾਡੀ ਸੰਸਥਾ ਦੀਆਂ ਹੁੰਦੀਆਂ ਹਨ, ਅਤੇ ਇੰਜਨ ਉਨ੍ਹਾਂ ਨੂੰ ਜੋੜ ਕੇ ਲਾਗੂ ਕਰਦਾ ਹੈ। ਇੱਕ ਸ਼ਬਦਾਵਲੀ ਪੰਜ ਇੰਜਨਾਂ ਨੂੰ ਸੰਭਾਲ ਸਕਦੀ ਹੈ, ਅਤੇ ਇੱਕ ਸੋਧ ਸਾਰੇ ਪੰਜਾਂ ਤੱਕ ਪਹੁੰਚ ਜਾਂਦੀ ਹੈ। ਕੋਈ ਤਬਦੀਲੀ ਲਾਈਵ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ ਉਸਨੂੰ [Playground](https://lingo.dev/en/docs/platform/playground) ਵਿੱਚ ਪਰਖੋ: ਇੱਕ ਇੰਜਨ ਦੀ ਤੁਲਨਾ ਇੱਕ ਕੱਚੇ ਮਾਡਲ ਨਾਲ ਕਰੋ, ਜਾਂ ਦੋ ਇੰਜਨਾਂ ਨੂੰ ਨਾਲ-ਨਾਲ ਵੇਖੋ। ਇੰਜਨ ਪਲੇਟਫਾਰਮ 'ਤੇ ਸੰਰਚਿਤ ਕੀਤੇ ਜਾਂਦੇ ਹਨ, ਜਿੱਥੇ ਸਥਾਨਕੀਕਰਨ ਟੀਮ ਆਪਣਾ ਸਥਾਨਕੀਕਰਨ ਢਾਂਚਾ ਚਲਾਉਂਦੀ ਹੈ।

## ਕੋਡ ਤੋਂ ਆਪਣੇ ਇੰਜਨਾਂ ਤੱਕ ਪਹੁੰਚੋ

ਕਿਸੇ ਰਿਪੋਜ਼ਿਟਰੀ ਵਿੱਚਲੀ ਸਮੱਗਰੀ ਦਾ ਅਨੁਵਾਦ ਕਰੋ। `lingo push` ਫਾਈਲਾਂ ਨੂੰ `.lingo/config.json` ਵਿੱਚ ਦਰਜ ਇੰਜਨ ਨੂੰ ਭੇਜਦਾ ਹੈ, ਅਤੇ `lingo pull` ਕਿਸੇ ਵੀ ਮਸ਼ੀਨ ਤੋਂ ਅਨੁਵਾਦ ਵਾਪਸ ਲਿਖਦਾ ਹੈ:

```bash
npm install -g @lingo.dev/cli
lingo init && lingo link
lingo push
```

ਜਾਂ ਕਿਸੇ ਇੰਜਨ ਨੂੰ ਸਿੱਧਾ ਕਾਲ ਕਰੋ, ਉਸਨੂੰ ID ਨਾਲ ਦਰਸਾਉਂਦੇ ਹੋਏ:

```javascript
const res = await fetch("https://api.lingo.dev/process/localize", {
  method: "POST",
  headers: { "X-API-Key": process.env.LINGO_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({
    engineId: "eng_abc123",
    sourceLocale: "en",
    targetLocale: "de",
    data: { greeting: "Hello, world!", cta: "Get started" },
  }),
});

const { data, model, usage } = await res.json();
// data:  { greeting: "Hallo, Welt!", cta: "Jetzt starten" }
// model: "anthropic/claude-sonnet-4.5"
// usage: { inputTokens: 2789, outputTokens: 861, cost: 0.023012 }
```
